# German B1.2 Curriculum Architecture

This file is architecture, not learner-facing lesson copy. It defines the authoritative module and learning-unit plan for the German track. Daily sessions select activities from these learning units according to the session-length rules in `../13-session-authoring-standard.md`; one learning unit is not equivalent to one daily session.

## Sublevel Contract

- Purpose: strengthen independent use across formal, professional, and civic situations.
- Entry profile: B1.1 argument basics, narration, routine mediation, practical writing.
- Exit profile: Learner can participate in discussions, write structured texts, handle formal requests, and summarize accessible source material.
- Skill profile: sustained everyday discourse, B1 argumentation, purposeful revision.
- Module count: 10.
- Learning-unit count: 50.
- Learning-unit fields: the unit ID gives CEFR sublevel and module; each row includes communicative objective, prerequisites/review, grammar, vocabulary, pronunciation, listening, speaking, reading, writing, interaction, mediation, pragmatic-cultural objectives, real-world task, activity architecture with duration and priority, difficulty, assessment tags, and progression status.

## Sublevel Assessment Architecture

- Weekly checks: short retrieval, vocabulary/grammar-in-context, listening or reading detail, and one production item selected from current modules.
- Module assessment: integrated task evidence from U05 plus a focused knowledge check on module grammar, vocabulary, pronunciation, and pragmatic-cultural conventions.
- Final integrated assessment: combines listening, reading, spoken interaction, written production, mediation, and reflection using the sublevel exit profile.
- Progression decision: learner advances when core module evidence, weekly checks, and final integrated assessment meet the thresholds in `../11-assessment-framework.md`.

## Resource Architecture

- Core resources: model dialogues or texts, vocabulary set, grammar-in-context prompt set, audio script, pronunciation cue, controlled practice bank, production rubric, and real-world task card.
- Optional resources: remedial explanations, alternate input texts, extension prompts, cultural/pragmatic notes, and assessment variants.
