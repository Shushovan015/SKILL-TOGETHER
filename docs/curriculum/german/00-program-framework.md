# German Curriculum Program Framework

This framework is the authoritative curriculum architecture for the German track from A1.1 through C2.2. It defines progression, modules, learning-unit architecture, assessment design, and resource architecture. It is not a bank of full learner-facing lessons and it is not a mass seed-content source.

## Authoritative Scope

- CEFR sublevels: A1.1, A1.2, A2.1, A2.2, B1.1, B1.2, B2.1, B2.2, C1.1, C1.2, C2.1, C2.2.
- Each sublevel contains 10 ordered modules.
- Each module contains 5 ordered learning units.
- Total architecture: 12 sublevels, 120 modules, 600 learning units.
- Daily sessions are assembled from activity blocks; one learning unit is not one daily session.

## Learning-Unit Contract

Every learning unit must define these fields before it can be authored as learner-facing content:

| Field | Required content |
|---|---|
| Title and ID | CEFR sublevel, module number, unit number, and descriptive title. |
| Communicative objective | What the learner can do in German after the unit. |
| CEFR sublevel and module | Encoded in the unit ID and repeated in module context. |
| Prerequisites | Prior module/unit concepts and any retrieval targets. |
| Grammar focus | One primary grammar target plus review grammar when needed. |
| Vocabulary focus | Domain vocabulary, collocations, chunks, and lexical strategy. |
| Pronunciation focus | Segmental, suprasegmental, fluency, or performance target. |
| Skill objectives | Listening, speaking, reading, writing, interaction, mediation, and pragmatic-cultural objectives when relevant. |
| Real-world task | Evidence-bearing task that approximates authentic use. |
| Review concepts | Retrieval targets from earlier units or modules. |
| Estimated activity time | Sum of authored activity durations, not a session length. |
| Difficulty | Sublevel-relative difficulty label. |
| Assessment tags | Searchable tags for checks, rubrics, and remediation. |
| Progression status | NEW, REVIEW, CONSOLIDATION, or EXPANSION. |

## Session Assembly

| Session length | Core pattern |
|---:|---|
| 30 min | Retrieval, input or skill focus, controlled practice, knowledge check. |
| 45 min | 30-minute core plus guided production or mediation. |
| 60 min | 45-minute pattern plus reading/listening depth and real-world task preparation. |
| 90 min | Full integrated pathway: retrieval, input, receptive work, pronunciation, production, mediation, task evidence, reflection. |

No duplicate learning-unit records are created for different session lengths. Session length is resolved by activity selection, priority, and scheduling rules.
