## Lexical Control Milestones

| Level band | Control target |
|---|---|
| A1 | Memorized chunks, concrete nouns, high-frequency verbs, basic formulae. |
| A2 | Productive everyday domains, predictable collocations, simple paraphrase. |
| B1 | Independent domain vocabulary, opinion phrases, formal request language, repair strategies. |
| B2 | Collocation depth, source-attribution verbs, evidence language, register distinction, domain transfer. |
| C1 | Idiom recognition, precise abstract vocabulary, genre-sensitive terminology, strategic paraphrase. |
| C2 | Nuance, connotation, rhetorical effect, cultural references, publishable lexical precision. |
