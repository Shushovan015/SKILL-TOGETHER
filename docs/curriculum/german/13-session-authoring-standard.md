# German Session Authoring Standard

This standard defines how daily sessions are assembled from learning-unit activities. A learning unit is a curriculum container; a session is a scheduled selection of activity blocks.

## Activity Contract

Each activity authored under a learning unit must include:

| Field | Required values |
|---|---|
| activity type | explanation/input, vocabulary activity, grammar-in-context, listening, reading, pronunciation, controlled practice, guided production, independent production, speaking, writing, interaction, mediation, retrieval/review, knowledge check, or real-world task |
| estimated duration | Minutes required by an average learner. |
| priority | CORE, RECOMMENDED, or EXTENSION. |
| skill tags | listening, speaking, reading, writing, interaction, mediation, pronunciation, grammar, vocabulary, pragmatics/culture. |
| prerequisite tags | Prior units or concepts required. |
| evidence | Completion signal: answer key, rubric, uploaded text/audio, reflection, or checklist. |
| recovery behavior | Whether failed or skipped activity triggers review, remediation, or rescheduling. |

## Session Length Patterns

| Length | Activity selection rule | Example composition |
|---:|---|---|
| 30 min | Select CORE retrieval, one primary input/skill activity, one practice block, one knowledge check. | retrieval 4, input 6, controlled practice 12, check 3, buffer 5. |
| 45 min | Include all 30-minute CORE work plus one RECOMMENDED guided production or pronunciation block. | retrieval 4, input 6, listening/reading 8, practice 10, guided production 10, check 4, buffer 3. |
| 60 min | Include receptive depth plus production evidence; at least one speaking/writing/mediation activity. | retrieval 5, input 8, receptive 12, grammar/vocab 10, production 15, check/reflection 5, buffer 5. |
| 90 min | Full integrated session: retrieval, input, receptive work, pronunciation, controlled practice, guided/independent production, mediation or interaction, real-world task, reflection. | retrieval 6, input 10, receptive 15, pronunciation 8, practice 12, production 18, task 15, reflection 6. |

## Scheduling Rules

- CORE activities are selected first.
- RECOMMENDED activities are included when time permits or when remediation requires them.
- EXTENSION activities are used for longer sessions, acceleration, or high-performing learners.
- Activities may span multiple sessions when their estimated duration exceeds available time.
- A session may draw from more than one learning unit for retrieval, review, or integration.
- Review concepts must be scheduled through spaced retrieval and recovery paths, not only final assessments.

## Quality Bar

- Every session must end with a visible proof of learning: checked answers, task evidence, written text, recorded speech, or a reflection linked to a rubric.
- A daily session cannot consist only of explanation.
- Pronunciation and pragmatic-cultural objectives must appear regularly, not only in speaking-heavy modules.
- Learner-facing copy must be authored separately from this architecture and reviewed for clarity, accessibility, and level fit.
