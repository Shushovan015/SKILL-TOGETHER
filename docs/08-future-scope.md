# Future Scope

Future-scope ideas must not be implemented during MVP work unless the scope documents and implementation roadmap are intentionally revised.

## Priority 1: Near-Term Enhancements

- Password reset and email verification if not completed in the MVP hardening phase.
- Richer administrator review workflows with reviewer assignment and comments.
- Improved revision planner based on weak-topic history.
- Additional predefined Learning Tracks.
- Calendar export, not full two-way integration.
- More detailed portfolio tracking for Software Engineering and Project Management.
- Configurable assessment difficulty by learner level.

## Priority 2: AI Enhancements

- AI-generated extra practice questions grounded in approved Lesson content.
- AI-assisted feedback for written answers with reviewer override.
- AI weekly reflection summaries visible only to the learner by default.
- AI explanation style preferences.
- Prompt and response analytics with privacy controls.

Guardrails:

- AI must not create official assessments from unapproved sources.
- AI must not decide authorization.
- AI must not control deterministic scheduling.
- AI must not overwrite approved curriculum.

## Priority 3: Collaboration and Integrations

- Calendar integrations.
- Real-time partner messaging.
- Study groups.
- Organization or cohort accounts.
- Mentor review workflows.
- External tool integrations for GitHub portfolios, project documents, or language resources.

## Priority 4: Commercial and Public Features

- Payments.
- Subscriptions.
- Public course marketplace.
- Public social profiles.
- Certificates.
- Leaderboards.
- Public curriculum publishing.

## Priority 5: Platform Expansion

- Native mobile applications.
- Voice tutoring.
- Video hosting.
- Advanced analytics.
- Adaptive long-term curriculum generation.
- Multi-tenant organization administration.

## Future-Scope Evaluation Criteria

Before adding any future feature, document:

- user problem;
- privacy impact;
- security impact;
- operational cost;
- dependency risk;
- whether it changes MVP domain rules;
- whether it requires new acceptance criteria;
- whether it can be added without disrupting completed learning history.
